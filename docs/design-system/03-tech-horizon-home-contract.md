# Tech Horizon Public Home Contract

Status: First implementation slice.

## Visual direction
Approved direction: Tech Horizon.

Core visual ideas:
- Deep navy / white theme pair.
- Blue → violet → cyan brand gradient.
- Connected cube-network visual language.
- Strong bilingual typography.
- High-contrast product cards with restrained glass surfaces.
- Reusable public header/footer rather than page-owned navigation.

## Reuse rules
- Theme and language remain platform-global capabilities.
- Brand mark is a reusable SVG asset.
- Public navigation and footer are shared layout components.
- Home sections consume global design tokens.
- PrimeNG and `bgp-*` components remain the shared UI foundation for interactive app surfaces.
