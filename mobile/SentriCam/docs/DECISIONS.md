# Architecture decisions

Architecture Decision Records capture durable choices and their tradeoffs. Accepted records describe the current direction; changing one requires a superseding ADR rather than silently rewriting history.

| ADR | Status | Decision |
| --- | --- | --- |
| [0001](adr/0001-monorepo.md) | Accepted | Organize platform code as independent roots in one monorepo |
| [0002](adr/0002-device-domain.md) | Accepted | Use Device as the shared platform domain with separate local/server identities |
| [0003](adr/0003-local-hub.md) | Accepted | Make Local Hub the local-first deployment model |
| [0004](adr/0004-outbox.md) | Accepted | Reserve durable integration publication through an outbox |
| [0005](adr/0005-signalr-adapter.md) | Accepted | Keep SignalR as a thin transport adapter |
